Гребля 360 · 1.27.0

Пять новых отсечек: круг Монако — 3 337 м, Эгюий-дю-Миди — 3 842 м, круг Индианаполиса — 4 023,36 м, Маттерхорн — 4 478 м и пять километров — 5 000 м. Всего 18 рубежей. У каждого есть иллюстрация, показ на пять секунд при достижении и карточка с прежними уровнями медалей. Прошлые тренировки учитываются. За отсечки монеты не выдаются.

Интерфейс тренировки: убран показатель «Консоль / 500 м», восемь оставшихся карточек расположены в две строки.
В достижениях добавлена вкладка «Последние» с сортировкой полученных медалей всех категорий по времени. Время новых наград сохраняется, прежние награды отмечены как полученные ранее без точной даты.
В профиле — необязательное поле «День рождения» в формате дд.мм.гггг с проверкой даты. Реакции питомцев повторяются дважды.
История показывает пять последних тренировок, кнопка «Показать еще» добавляет по пять. Убраны подписи «Каждый гребок в счёт» и «Тренировки под вас».

Начиная с этой версии, следующие обновления скачиваются внутри приложения с прогрессом. До установки проверяются размер, SHA-256, пакет, версия и подпись. Установка проходит через системное окно Android; при первом использовании нужно разрешить «Гребле 360» установку обновлений. Скачанный APK сохраняется для повторной попытки и проверяется при следующем открытии.

Старые установщики, скачанные внутри приложения, очищаются автоматически после обновления. Для удаления старых APK из браузера откройте Профиль → Прочие настройки → Обновления приложения → Старые установщики APK и разрешите доступ к файлам в Android. Очистка удаляет только более старые версии нашего пакета с совпадающей подписью; текущая, более новые версии и другие файлы остаются. Доступ к общей памяти не нужен для скачивания, установки и очистки внутренних обновлений.

Устанавливайте поверх текущей версии. История, питомец, корм, монеты и покупки сохраняются.
