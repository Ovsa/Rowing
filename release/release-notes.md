# Гребля 360 · 1.31.0

- Телефон получает опубликованный каталог достижений от домашнего сервера v6 через уже настроенную привязку. Каталог сохраняется на телефоне для работы без сети.
- Витрина поддерживает пользовательские категории, правила и уровни. Изменения затрагивают будущие начисления, ранее выданные монеты сохраняются.
- На ПК доступны вкладки «Достижения», «Выпуск APK» и «Прогресс участников».

Устанавливайте APK поверх предыдущей версии.
