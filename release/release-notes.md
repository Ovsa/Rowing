Гребля 360 · 1.27.1

Обновление для установки поверх 1.26.2. История, профиль, питомец, покупки и монеты сохраняются.

• APK скачивается внутри приложения. Сохранены резервный GitHub API и проверки размера, SHA-256, пакета, версии и подписи. Старые APK приложения можно очищать в настройках обновлений.
• Новые отсечки до 5 км, вкладка «Последние» в достижениях и поле «День рождения» в профиле.
• История по пять записей с кнопкой «Показать ещё», двойные реакции питомцев и восемь показателей на экране тренировки.
• Добавлен экспериментальный расчёт калорий по разности сумм на конец и начало тренировки из одного импорта Mi Fitness / Health Connect. Когда границы калорийных интервалов не совпадают с тренировкой, результат помечен «Mi Fitness · разность ≈». Точные импортированные калории и ручной ввод имеют приоритет. Неполные, перекрывающиеся и суточные записи не превращаются в калории тренировки: для них остаётся ручной ввод.

Версия 1.27.1 имеет новый внутренний номер 31: Android сможет установить её поверх переходной 1.26.2 с номером 30. Удалять приложение не требуется. Установку подтверждает системный установщик Android.
