Гребля 360 · 1.26.2

Переходный выпуск для исправления обновлений. При сбое обычной ссылки приложение получает update.json и APK через официальный GitHub API. Скачивание выполняется внутри приложения с прогрессом; размер, SHA-256, пакет, версия и подпись проверяются перед открытием установщика Android.

Основные экраны, питомец, история и шкала расстояний сохранены как в 1.26.1. Новые функции 1.27 и расчёт калорий по разности будут выпущены после проверки этой версии на обоих телефонах.

Установите этот APK вручную поверх 1.26.1. Удалять приложение не нужно: профиль, история, монеты и покупки сохраняются. При первой установке обновления из самого приложения Android запросит разрешение на установку для «Гребли 360».
