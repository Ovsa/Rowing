# Гребля 360 · 1.31.14

- Полная версия и Lite объединены в одном приложении. Переключатель: «Профиль → Прочие настройки → Режим приложения». История, профиль, оформление и полученные достижения общие.
- Lite сразу запускает свободную запись. На экране: гребки, расстояние, время и темп гребли. Уровень нагрузки вынесен в широкую плашку под четырьмя показателями.
- В Lite работают полноэкранные отсечки и достижения, без начисления новых монет. За полученные в Lite достижения монеты не добавятся после возврата в полный режим. Ранее заработанный баланс сохраняется.
- Обновления разделены: полный режим проверяет main, Lite — только ветку lite и её выпуски. Кэш и предложения обновлений изолированы между каналами.
- Основной адрес обновлений Lite — прямой файл из ветки, без квоты GitHub API. Резервный запрос также читает только ветку lite.
- Переключить режим можно после завершения тренировки. Поиск в Lite показывает все BLE-устройства, включая консоль без имени.
