# Гребля 360 · 1.30.3

- Если Mi Fitness передал пульс без активных калорий за тренировку, приложение повторяет проверку при возврате и каждые 15 минут, пока оно открыто. Это касается записей за последние семь дней.
- Как только Health Connect отдаёт активные калории за совпадающий сеанс, они обновляют существующую запись. Ручные значения сохраняются. Расчёт по широким интервалам по-прежнему показан отдельно.

Устанавливайте APK поверх предыдущей версии. Домашний сервер обновлять не требуется.
