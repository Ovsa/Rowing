# Гребля 360 · 1.31.12

- В «Профиль → Прочие настройки → Запись тренировки» добавлен чекбокс «Отображать программы».
- Если чекбокс включён, перед стартом появляется привычный выбор свободной тренировки или программы. Для существующих пользователей настройка включена по умолчанию.
- Если чекбокс выключен, «Начать» сразу запускает свободную запись без меню и обратного отсчёта. Тот же режим применяется при старте с первых гребков и после подключения к запомненному тренажёру.
- Настройка сохраняется между запусками. Изменить её можно после завершения текущей тренировки.
