# Гребля 360 · 1.30.2

- «Наш прогресс» показывает компактные полосы целей двух участников. Передача включается вместе с калориями.
- Показатели на экране тренировки крупнее. Для программ добавлены отдельные таймеры тренировки и ступени, уменьшен график и показан полноэкранный отсчёт с нужным уровнем нагрузки.
- В историях программ и свободной гребли сохраняется средний пульс из итогов браслета либо из доступных измерений во время записи.
- Калории консоли считаются за текущую запись. При импорте активные и общие калории показываются по источнику, а разность по широким интервалам отображается отдельно как оценка. Ручные значения сохраняются при повторном импорте.

Устанавливайте APK поверх предыдущей версии. Для целей участников требуется домашний сервер v5.
