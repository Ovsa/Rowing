# Гребля 360

Android-приложение для домашних тренировок на гребном тренажёре UNIX Fit 360.

[Скачать последнюю версию](https://github.com/Ovsa/Rowing/releases/latest)

Устанавливайте APK поверх предыдущей версии: профиль, история, питомец и монеты сохраняются.

В версии **1.23.0**: точное расстояние по нажатию на достижение-отсечку, магазин с вкладками питомцев и «Общее», цельные шапки с мягким контуром и движением по кадрам головы. Проверка обновлений выполняется при каждом открытии приложения и возврате из фона. Купленные шапки по 10 монет и снег за 15 сохраняются; повторная покупка не нужна.

С версии 1.20.0 приложение проверяет новые выпуски этого репозитория и предлагает скачать обновление. Установку подтверждает пользователь в Android. Ручная проверка доступна в **Профиль → Прочие настройки → Обновления приложения**.

## Публикация обновлений

В каталоге `release` лежат три подготовленных файла: подписанный APK, `update.json` и описание изменений `release-notes.md`. После изменения файлов и push в `main` workflow **Publish Row360 APK** проверяет размер, SHA-256 и параметры манифеста, загружает файлы в черновик Release и публикует его как **Latest**. Можно повторно запустить workflow вручную во вкладке Actions. Повторный запуск проверяет уже опубликованный выпуск, не перезаписывая его файлы.

Для новой версии увеличьте `versionCode`, сохраните прежний ключ подписи и замените содержимое `release` файлами новой сборки. Тег и имя APK берутся из `update.json`. Опубликованную версию изменять нельзя: исправления выпускаются с новым номером.

Публичный адрес для проверки приложением:

`https://github.com/Ovsa/Rowing/releases/latest/download/update.json`

Ключ подписи APK остаётся на компьютере разработчика. Workflow использует временный `GITHUB_TOKEN` только для выпуска в этом репозитории; дополнительные токены и секреты не требуются.
