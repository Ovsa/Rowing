# Гребля 360

Android-приложение для домашних тренировок на гребном тренажёре UNIX Fit 360.

[Скачать последнюю версию](https://github.com/Ovsa/Rowing/releases/latest)

Устанавливайте APK поверх предыдущей версии: профиль, история, питомец и монеты сохраняются.

Актуальный стабильный выпуск — **1.28.0** (внутренний номер 33), для обновления поверх **1.26.2 / 1.27.x**. APK скачивается внутри приложения; перед установкой проверяются подпись, версия, размер и SHA-256. Android запрашивает подтверждение установки.

На главной — виджет «Цель»: календарный срок, калории, волны в цвете темы и история вклада тренировок. Срок — от 7 дней. Недельный минимум: **500 ккал для женского профиля**, **800 ккал для мужского**; другие сроки рассчитываются пропорционально дням с округлением вверх. Выбранная дата включается целиком.

Награда: 3 монеты за каждую полную неделю плюс 1 за каждые полные 200 ккал сверх минимума срока. Женский профиль: 14 дней / 1000 ккал → 6 монет, 1200 → 7; мужской: 1600 → 6, 1800 → 7. Условия начатой цели фиксируются. Импорт и исправления обновляют вклад без дублирования, награда выдаётся один раз.

Отсечка показывается на всём экране тренировки в течение 5 секунд. В истории можно указать гребки вручную: дистанция считается по последнему уровню записи, обновляются темп, статистика и монеты, доступны исходные показания для возврата. Время и калории сохраняются.

В «Последних» остаются четыре достижения; подходящие уровни и скрытые достижения дают по 3 монеты. За отсечки монет нет. Bluetooth-подключение и команды тренажёру сохранены как в 1.27.2.

Кормление — 200 ккал через три календарных дня: в день кормления без корма питомец грустит, запас можно пополнить до конца суток. Неделя запаса начинается с регистрации питомца. Однократно после обновления выдаётся 200 ккал в резерв на следующую неделю; регулярный резерв 50 ккал при 800 ккал за неделю сохраняется.

С версии 1.20.0 приложение проверяет новые выпуски этого репозитория и предлагает скачать обновление внутри приложения. Установку подтверждает пользователь в Android. Ручная проверка доступна в **Профиль → Прочие настройки → Обновления приложения**.

## Публикация обновлений

В каталоге `release` лежат три подготовленных файла: подписанный APK, `update.json` и описание изменений `release-notes.md`. После изменения файлов и push в `main` workflow **Publish Row360 APK** проверяет размер, SHA-256 и параметры манифеста, загружает файлы в черновик Release и публикует его как **Latest**. Можно повторно запустить workflow вручную во вкладке Actions. Повторный запуск проверяет уже опубликованный выпуск, не перезаписывая его файлы.

Для новой версии увеличьте `versionCode`, сохраните прежний ключ подписи и замените содержимое `release` файлами новой сборки. Тег и имя APK берутся из `update.json`. Опубликованную версию изменять нельзя: исправления выпускаются с новым номером.

Публичный адрес для проверки приложением:

`https://github.com/Ovsa/Rowing/releases/latest/download/update.json`

Ключ подписи APK остаётся на компьютере разработчика. Workflow использует временный `GITHUB_TOKEN` только для выпуска в этом репозитории; дополнительные токены и секреты не требуются.
